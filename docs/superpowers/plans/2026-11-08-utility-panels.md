# 导航管理交互修正计划

目标：修正辅助面板挤动主布局的问题，精简产品入口，改善列表阅读。
基线：远端 feat/bookmarks-ui-polish / 29b05ac。先读 HANDOFF.md；不合并或部署 main。

1. 两个辅助面板移到 body 下，采用 fixed 浮层；单一状态为关闭/外观/数据。点击触发器、切换面板、外部点击、Escape、键盘焦点移出、打开编辑框都经过同一状态转换。关闭与 aria-expanded 同步；Escape 恢复触发器焦点；窗口变化只重新定位，不重排主布局。
2. 外观直接显示色板，增加恢复默认。设置先写入成功再绘制；重置只删除 nav_accent 并移除内联颜色覆盖，不改变深浅主题和列数。读取不写回。
3. 移除演示入口、演示数据与状态分支；测试数据仅保留在 tests。移除恢复入口和自动快照写入，历史存储不主动删除。JSON 导入校验/覆盖确认/写入失败保护保留；异步读取只提交最后一次选择。
4. 列表保持68px桌面行高、分页与无固定列数上限；名称/网址两行、独立描述区与分类、固定操作区，小屏隐藏次要列。修改现有样式规则，不追加新的覆盖文件。
5. 先执行新增失败测试，再实现；更新明确退役功能的旧测试，保留关键保护断言。提供真实浏览器布局不位移、深浅主题、列表、小屏、file、导入失败及性能用例；受环境限制未运行的检查明确报告。
6. 打包预览、保历史提交、更新 HANDOFF 与 Notion。触发CI后停止轮询。
