# 截图绿色与仓库同步

## 变更

用户提供按钮截图，要求以其色系调整默认主题，并在上传前分支备份现有导航代码。主填色取样为RGB(115,213,72)，即#73D548。默认改为鲜叶绿；其他预设使用相近的明亮感，不再以灰粉、灰绿为主。保留浅色背景、淡色分类选中态、圆角焦点及现有布局。

浅/深主题的normal、hover、soft和focus变量通过现有createAccentPalette统一生成。亮绿底搭配#263A32约6.54:1，截图中的白字仅约1.85:1；保留参考背景，选择可读文字，而非降低参考绿饱和度。已有nav_accent不强制替换，恢复默认可获得新色。

本次同步包括此前本地UI规范整改和移除列表的源文件：持久字段/任务错误、模态背景隔离、合法链接与按钮结构、更多操作状态、非拖动排序、无固定列数上限、独立浮层、JSON导入导出。无演示、自动快照或列表。UI_DESIGN_STANDARD.md保持用户原文。

## 动态主题色图标

采用统一SVG书签罗盘：用户更换主题色时，同步更新侧栏品牌Logo、浏览器标签页SVG favicon的data URL和meta theme-color。刷新后从nav_accent重新生成，恢复默认则回到#73D548。动态favicon不依赖网络或外部图标服务。ICO、16/32 PNG、Apple Touch 180、Android 192/512为静态回退和安装图标；已安装快捷方式的图标不保证随网页运行时状态变化。

浏览器测试覆盖主题色更新、深浅主题切换、刷新持久化和恢复默认。静态测试检查所有图标资源签名/尺寸及构建打包。对比度回归修正：选中柔和底使用按背景计算的中性前景，hover加深30并按hover背景选择黑/白/深墨色前景；保持4.5:1断言。
