# 我的导航

原生 HTML / CSS / JavaScript 个人书签页，收藏保存在当前浏览器，无需后端。

## 使用

预览包完整解压后打开 `preview/index.html`，保留同目录全部资源。仓库下载包则打开根目录 `index.html`。正式站点由 `main` 分支的 GitHub Pages 工作流部署。

## 布局与浏览

- 仅保留卡片网格；搜索和分类筛选结果连续显示，不分页。
- 由整个页面自然纵向浏览；书签网格和分类导航不建立独立滚动区域。
- 桌面列数是独立用户偏好，保存在 `nav_columns`，默认4列、最少1列，没有产品级列数上限。桌面窗口缩放不会改写这个偏好。
- 移动端在宽度不超过700 CSS px时使用两列，极窄屏（不超过360 CSS px）使用单列；这是独立的移动端布局，不覆盖桌面列数。回到桌面后恢复原偏好。
- 外观设置提供紧凑与舒适两种密度，保存在 `nav_density`。紧凑模式约72 CSS px高，显示图标、名称和网址；舒适模式约112 CSS px高，额外显示描述。密度切换不修改列数或收藏。
- 桌面8列、24个书签在1334×657 CSS px视口的一屏显示路径已有 Chromium 回归测试。

支持搜索、分类、添加、编辑、删除、拖拽排序、上移下移和分类排序。旧版列表视图设置会被忽略，不改写收藏数据。

## 外观与图标

默认鲜叶绿 `#73D548` 取自用户提供的按钮截图，另提供薄荷绿、湖水青、晴空蓝、矢车菊蓝、鸢尾紫、樱花粉、蜜杏橙、柠檬黄。更换主题色会同步更新侧栏书签罗盘 Logo、浏览器标签页 SVG favicon 和支持动态更新的浏览器工具栏颜色；Apple Touch / Android 安装图标是静态资源，不随网页运行时颜色变化。保留自定义颜色和“恢复默认”；已有自定义色不强制替换。搜索框使用主题色焦点样式，不显示黑色方框。

## 数据与备份

仅保留 JSON 导入、导出。导入先整批校验并确认覆盖；取消、读取/解析/写入失败时保留原收藏，不创建自动快照。没有演示数据或“恢复上次备份”入口。

更新前建议导出 JSON 并保留旧页面；不同路径、域名、端口和浏览器可能使用独立存储。Git 分支备份只保存代码，不包含用户浏览器内的书签，也不替代 JSON 数据备份。

## 开发与验收

先读 `HANDOFF.md`、`AGENTS.md`、`UI_DESIGN_STANDARD.md`。使用 Node.js 24 和仓库锁定依赖：

```sh
npm ci
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:browser
```

连续网格与双密度版本的 GitHub Actions 验收：
- 单元测试：103项通过。
- Preflight 与静态构建：通过。
- Chromium：59项通过。
- 关键路径覆盖列数偏好、窗口缩放、移动端重排、24项一屏、连续筛选、长分类自然展开、密度持久化、深浅主题、弹窗、编辑和错误恢复。

10,000条书签压力用例验证了10,000个卡片与懒加载图片节点、文档连续高度和 `content-visibility:auto`。GitHub Ubuntu Chromium runner 上初次挂载约1分钟；这是压力测试记录，不代表一般收藏量的加载时间，也不作为所有设备的性能保证。5,000条数据下切换工具面板的30次样本P95约0.8ms，未触发书签网格子节点变化。详见 `HANDOFF.md` 和 `design-qa.md`。

`dist/manifest.json` 记录运行与许可文件的SHA256，包含 SVG favicon、多分辨率 ICO/PNG、Apple Touch 与 Android 图标。第三方UI图标为本地SVG CSS mask，保留 `THIRD_PARTY_NOTICES.md`；不分发字体文件。已保存的相对图标路径优先按导航页自身路径解析，保持旧收藏兼容；若该路径不可用，再尝试按书签网站地址解析，最后继续自动获取网站 favicon。绝对图标地址保持不变。外站favicon可能依赖网络，加载中显示本地图标占位，失败后保留回退。不改变原仓库整体许可。
