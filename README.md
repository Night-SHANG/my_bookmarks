# 我的导航

个人网址导航，原生 HTML / CSS / JavaScript，数据保存在当前浏览器。

## 视觉统一预览

暖白与森林绿、分类侧栏、收藏卡片 / 列表视图；保留搜索、增删改、拖动排序、主题色和列数、JSON 导入导出；底部分页按视口完整行计算容量。

本轮在原有开发版上统一配色、字体、按钮、卡片与深浅主题，不增加新的业务功能。`polish.css` 是独立美化层；`icons.css` 内置页面所需的 SVG 图标，不再依赖远程 UI 图标字体或 Google Fonts。当前继续精简非必要文案，并取消列数的固定上限。最新约束、状态转换、验证边界和注意事项见 `HANDOFF.md`；历史视觉记录保留在 `docs/visual-polish-2026-11-08.md`。

外观设置与导入导出使用独立浮层，点击空白处或按 Escape 关闭；两个面板互斥。主题色支持恢复默认，不会同时重置深浅模式、列数或书签。已移除演示入口和自动备份恢复功能。列表将名称与网址上下对齐，描述和分类独立排列，小屏保留主要信息。

## 直接打开预览

解压交付包后，直接双击 `preview/index.html`。请保留同目录的 CSS、JS 与图标文件，无需安装 Node 或启动服务器。顶栏可调整列数；书签超过首屏容量时使用底部页码。桌面默认4列、最低偏好4列，不设10列等固定上限；旧3列设置按4列读取。实际显示列数仍按窗口可用宽度适配，卡片保持可读；更宽的窗口可以显示11列及以上。缩放和切换列表不会覆盖保存的列数偏好。普通桌面预留至少4行固定尺寸槽位，只有1个书签、搜索只剩1项或尾页不足时，空位留白，卡片不会放大。窄屏/矮屏放不下时按可用空间减少实际列/行，不为留空强制滚动。

file:// 下本地存储由浏览器决定；更换文件路径或浏览器可能看到不同收藏，更新前请导出 JSON。HTTP 及 GitHub Pages 仍支持静态文件部署。

打开或刷新页面后即可直接输入搜索，不必先点击搜索框。聚焦只在初始化时执行一次，编辑/新增弹窗、分页和窗口缩放不会抢走当前输入焦点。移动浏览器是否弹出软键盘由其自身策略决定。

## 本地开发与验证

Node.js 24：

```sh
npm ci
npm run dev -- --host 0.0.0.0 --port 4173
npm test
npm run preflight
npm run build
```

打开本机 http://localhost:4173/。`dist/` 是静态产物，`manifest.json` 记录文件大小与 SHA256。部署时应包含 `polish.css`、`icons.css` 和第三方说明，而不只是原来的四个文件。

## 数据与 JSON 导入导出

原有 `my_nav_v2` 书签、`category_order` 排序、`favicon_cache_v1`、`nav_theme`、`nav_columns`、`nav_accent` 继续兼容。`nav_view` 记录网格/列表偏好。

备份以用户导出的 JSON 文件为准，不再创建浏览器内的自动快照。导入 JSON 会验证整批结构和 HTTP(S) 地址，再要求确认替换；导入前请先导出需保留的收藏。取消、解析失败、读取失败或存储失败都不会覆盖当前收藏；连续选择文件时，旧的异步读取不能覆盖最新选择。历史版本留下的快照键不主动删除，也不再提供恢复入口。损坏的原数据不会静默覆盖，可先导出原始文件用于修复。

本地存储不等于云同步；不同域名、端口和浏览器的数据相互独立。测试分支不会自动取得线上收藏，请在旧页面导出后，在预览中导入。清理浏览器数据前请导出备份。

## 外部资源与许可

UI 使用 Font Awesome Free 6.7.2 的 SVG 子集，许可证为 CC BY 4.0，已转换为本地 CSS mask，详情见 `THIRD_PARTY_NOTICES.md`。未捆绑字体文件；正文使用操作系统已有字体。网站 favicon 仍请求站点自身或 DuckDuckGo 服务，失败时显示本地通用图标；不承诺离线取得第三方网站 logo。

测试开发依赖 jsdom 26.1.0（MIT），不随运行时静态包发布。原仓库未声明项目整体开源许可证，本次不代替作者授予新许可。

历史设计与验证范围见 `docs/design-and-validation.md` 和 `design-qa.md`；当前状态以 `HANDOFF.md` 和对应提交的 CI 为准。

## Chromium 运行时回归

开发依赖固定 `@playwright/test` 1.56.1（Apache-2.0）。在支持 Chromium 的环境运行：

```sh
npx playwright install --with-deps chromium
npm run test:browser
```

开发分支 GitHub Actions 配置为运行全套快速回归与真实浏览器用例，并上传桌面、手机、弹窗、长分类与深色截图。测试阻断外部网络资源，检查本地图标和布局降级；新增用例覆盖10→11列、16列跨视图与缩放恢复、文案精简后的可访问名称，以及10,000条测试书签的DOM规模和筛选耗时。浏览器测试只使用 tests 目录中的测试夹具，不需要账户或额外 Secrets，也不部署线上。新增浮层与列表测试覆盖主界面坐标不变、焦点关闭、主题色重置、JSON 文件往返、小屏列表、file 入口和大量收藏下打开面板不重建书签网格；实际执行状态见 HANDOFF。

## 小窗口说明

电脑常规视口使用首屏分页；手机及高度不足以容纳完整卡片的小窗口，降级为每页一行、允许页面自然滚动，保证管理与表单控件仍可访问。列数设置保留用户偏好，窄屏实际列数会减少。
